Lineage path: Database Table → Data Source → Worksheet → Dashboard. Both asset-level (box-to-box) and column-level (field-to-field) edges are produced. Custom SQL parsing is what links a data source back to physical DB tables — that's the join between the Tableau graph and the rest of the catalog.
Supported
✓ Data Source → Worksheet (asset + column)
✓ Data Source → Dashboard (asset-level)
✓ Worksheet → Dashboard (asset + column)
✓ DB Table → Data Source via Custom SQL parse
Gaps / caveats
✗ No lineage for Flows, Metrics, embedded dashboards
✗ Workbook nodes excluded from traversal
⚠ Column-level needs assets refreshed recently
⚠ Flows unavailable under JWT bearer auth
